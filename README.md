# 🛒 E-Commerce Database Management System (SQL Server)

## 📌 Project Overview
Designed and implemented a relational database for an E-Commerce platform using SQL Server Management Studio (SSMS).

## 🛠️ Key Features & Skills Applied
- **Database Architecture:** Created normalized tables with proper Primary and Foreign Keys.
- **Data Manipulation:** Inserted, updated, and queried data.
- **T-SQL Queries:** Wrote queries including filtering (`WHERE`), conditional logic, and sorting (`ORDER BY ASC/DESC`).
